# 🚀 Advanced Tailwind Slider

First created simple but advanced image slider using **Tailwind CSS + JavaScript**, built with **DRY (Don’t Repeat Yourself)** principles.

A responsive, modern UI slider with dynamic buttons and smooth image switching.

---

## ✨ Features

- 🎨 Modern Tailwind UI design
- 🖼️ Dynamic image slider
- 🔘 Auto-generated buttons (DRY principle)
- 🎯 Active button state system
- 🔄 Image switching via JavaScript
- ⚡ Smooth transitions & hover effects
- 📱 Fully responsive layout

---

## 🧠 What I learned

- DOM manipulation
- Event listeners
- Dynamic element creation
- Active state handling
- Tailwind `@apply` usage
- Fixing DOM timing issues
- DRY coding style
